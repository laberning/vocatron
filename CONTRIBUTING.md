# Contributing to Vocatron

Issues are open. Pull requests are welcome for fixes, tests, documentation and targeted
improvements; for larger features or changes of the architecture, open an issue first.

The whole guide, with the setup, the checks (`make check`), the Definition of Done and the rules
for tests and documentation, is in [`docs/contributing.md`](docs/contributing.md).

In short: run `make setup`, make your change with tests on the lowest fitting stage, and run
`make check` before you open the pull request. Never add real song lyrics, songs, stems or model
files to the repository. Report security problems as described in [`SECURITY.md`](SECURITY.md).
